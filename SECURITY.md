# Security Policy

## Supported version

Security fixes are applied to the latest commit on `main`. Older deployments should update before requesting support.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's **Security → Advisories → New draft security advisory** flow so credentials, exploit details, and user data remain private.

Include the affected route or Discord event, reproduction steps, impact, and any suggested mitigation. Remove live Discord tokens, OAuth secrets, session cookies, encryption keys, transcripts, and database files from the report.

Maintainers should acknowledge a complete report within seven days, validate severity, and coordinate disclosure only after a fix is available.
